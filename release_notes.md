## BVN FPS Unlock v1.0

Frame-rate unlock plugin for 死神vs火影 竞技版 (Bleach vs. Naruto, Adobe AIR 50.2, tested on v3.8.8.6).

### Install
1. Download ps_unlock.swf below.
2. Copy it to <game>\assets\plugin\fps_unlock.swf.
3. Start (or restart) the game — it activates automatically; green HUD top-left.

### Controls
| Key | Action |
|---|---|
| F1 | toggle HUD |
| F2 / F3 | target +15 / -15 (Shift: +/-1) |
| F4 | toggle unlock / restore stock 60 |
| F5 | cycle presets 30/60/90/120/144/165/240 |
| F6 | dump live decrypted roster (dev) |

### Notes
- Netplay-safe: suspends itself during LAN/online lockstep matches (HUD shows NETPLAY LOCK).
- 120 Hz displays: 120 is the practical ceiling.
- 竞技版 uploads match records — keep it off (F4) for ranked/online play.
